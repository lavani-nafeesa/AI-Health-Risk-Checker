# AI Health Risk Checker

An AI-powered web application that analyzes health and lifestyle factors to provide a general health risk assessment.

## Features

- BMI Calculator
- AI-based Health Risk Prediction
- Health Score
- Risk Percentage
- Risk Level Classification
- Personalized Health Recommendations
- Diet and Exercise Suggestions
- Sleep and Hydration Recommendations
- Interactive Streamlit Dashboard

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest
- Streamlit
- Joblib

## Input Parameters

The application considers factors such as:

- Age
- Gender
- Height
- Weight
- Blood Pressure
- Glucose Level
- Sleep Hours
- Exercise
- Water Intake
- Stress Level
- Smoking
- Alcohol Consumption
